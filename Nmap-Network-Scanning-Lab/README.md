Nmap Network Scanning Lab

Project Overview

This project documents my hands-on learning and practical experience with Nmap, a network scanning and discovery tool.

Objectives

- Understand network scanning fundamentals.
- Learn TCP and UDP port concepts.
- Identify open, closed and filtered ports.
- Understand service and version detection.
- Analyze scan results.

Tools Used

- Kali Linux
- Nmap
- VirtualBox
- Ubuntu Virtual Machine

Practical Learning

- Basic host discovery
- TCP port scanning
- Service and version identification
- Understanding Nmap scan output
- Network troubleshooting fundamentals

Learning Outcomes

- Improved understanding of network reconnaissance.
- Better knowledge of ports and services.
- Practical familiarity with Nmap output analysis.

Environment

All practical activities were performed in a controlled virtual lab environment on systems owned by me or explicitly authorized for testing.

This project is intended for educational purposes and authorized security testing only.
